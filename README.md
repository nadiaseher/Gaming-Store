# 🎮 Gaming Store

A modern Gaming Store website built with React.js.

## 🚀 Features

- Modern gaming website UI
- Hero section with gaming background slider
- Search games functionality
- Category based game filtering
- Popular games cards
- Offer section
- Responsive design
- Modern navbar and footer

## 🛠 Technologies Used

- React.js
- JavaScript
- CSS
- Vite
